3. **O `support.js` que falta é o `dc-runtime.js`.** O `dc-runtime.js` do projeto é a concatenação exata, byte a byte,
   dos 3 scripts que renderizavam as pranchas antigas (React 10 751 B, ReactDOM 131 835 B e o runtime 45 305 B). Servir

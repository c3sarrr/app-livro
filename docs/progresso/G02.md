- [x] Achado 1: o serviço recusa `publish_via_partition_root` (PSYNC_S1143) → partições pelo nome + curinga `reading_sessions_%` no stream (11 partições replicadas).
- [x] Achado 2: `bucket_definitions` é legado → **Sync Streams** edição 3 com CTE `pro` em `billing.sync_access`.

- [x] Payloads `CrudEntry` → RPC: jsonb em texto, recusa sem travar o lote (operação guardada inteira), erro transitório repetido, HLC no futuro, partição fora do intervalo, formatos na volta.
